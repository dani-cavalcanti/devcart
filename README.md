# devcart
O **DevCart** é um e-commerce em microsserviços (Java 21/Spring Boot 3.4+) projetado para demonstrar na prática a ilusão dos 100% de cobertura de código por IA. Possui arquitetura *Database per Service* com API Gateway, Eureka, MongoDB, Redis e PostgreSQL, integrando PITest, jqwik e Pact JVM para validar resiliência e contratos de APIs.
